# Credits

Every third-party asset and library used by the game is recorded here with its creator,
license and source URL. Rules:

- Only free assets that allow commercial use. CC0 preferred.
- Never guess a credit. If a license is unclear, do not use the asset; make a placeholder in code.
- Add the entry in the same commit that adds the asset.
